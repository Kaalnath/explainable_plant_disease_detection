# Explainable Deep Learning for Plant Disease Detection

An explainable image-classification project using transfer learning,
EfficientNet, PyTorch, and Grad-CAM to identify plant leaf diseases.

## Objectives

- Classify healthy and diseased plant leaf images.
- Apply image preprocessing and data augmentation.
- Evaluate performance using accuracy, macro-F1, per-class recall,
  and confusion matrices.
- Generate Grad-CAM visualizations to inspect image regions
  influencing model predictions.
- Provide an image-upload interface for inference.

## Technology Stack

- Python
- PyTorch
- EfficientNet
- Grad-CAM
- scikit-learn
- Streamlit

## Project Status

Initial repository setup. Model training and evaluation are
